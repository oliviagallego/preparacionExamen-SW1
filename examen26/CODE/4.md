# Ejercicio 3 (Práctico) — “Citas médicas + Admin + Búsqueda + Cancelar”

## Contexto

Tienes una app de **citas**. Un usuario hace login y puede ver sus citas. Un admin puede ver **todas** las citas y **cancelarlas**.

### Datos (IMPORTANTE)

Las citas están guardadas como **OBJETO** en `database.appointments.data`.

---

## Código que te dan

### `/database.js`

```js
const appointments = {
  data: {
    101: { id: 101, patient: "Ana", date: "2026-01-28", status: "CONFIRMED" },
    102: { id: 102, patient: "Luis", date: "2026-01-30", status: "CONFIRMED" },
    103: { id: 103, patient: "Ana", date: "2026-02-01", status: "CANCELLED" },
  }
};

module.exports = { appointments };
```

### `app.js`

Ya existe:

* `checkLogin(req,res,next)`
* `requireAdmin(req,res,next)`
* `session + flash middleware`
* `res.locals.user` (para el header)

Y ya está montado:

```js
app.use("/admin", checkLogin, requireAdmin, adminRouter);
app.use("/appointments", checkLogin, appointmentsRouter);
```

---

# Lo que tienes que hacer

## A) RUTA usuario (restringida): `GET /appointments`

* Muestra **solo** las citas del usuario logeado.
* El username del usuario está en `req.session.user.username`
* Filtra por `patient === username`
* Renderiza `appointments.ejs` con `{ appointments }` (array)

Ejemplo: si el usuario es `"Ana"`, solo ve las citas de Ana.

---

## B) Admin: `GET /admin/appointments`

* Muestra **todas** las citas en tabla.
* Añade buscador GET por paciente:

  * `/admin/appointments?q=an`
  * filtra por `patient` (case-insensitive)
* Renderiza `admin_appointments.ejs` con `{ appointments, q }`

---

## C) Admin cancelar: `POST /admin/appointments/:id/cancel`

* Cambia la cita a `status = "CANCELLED"`
* Si no existe:

  * `req.session.error = "No existe esa cita"`
* Si existe:

  * `req.session.message = "Cita cancelada"`
* Redirige a `/admin/appointments`
