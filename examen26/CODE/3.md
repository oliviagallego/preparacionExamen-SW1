# Ejercicio 2 (Práctico) — “Productos + Carrito + Admin”

## Contexto

Tienes una tienda con:

* `/products` lista productos
* `/cart` muestra carrito (solo si estás logeado)
* `/admin/products` panel admin para **CRUD básico** de productos (listar, buscar, crear, borrar)
* Los productos están guardados en `database.products.data` como **OBJETO**.

---

## Archivos que te dan

### `database.js`  (**OBJETO**)

```js
const products = {
  data: {
    1: { id: 1, name: "Camiseta", price: 15 },
    2: { id: 2, name: "Sudadera", price: 30 },
    3: { id: 3, name: "Gorra", price: 12 }
  },
  nextId: 4
};

module.exports = { products };
```

### `app.js` (ya tiene session y flash, y user en res.locals)

Te dicen que ya existe `checkLogin(req,res,next)`.

---

#  Lo que tienes que hacer (enunciado)

## 1) RUTA pública: listado de productos

**Crea** `routes/products.js` con:

* `GET /products` → renderiza `products.ejs` con tabla.
* Debe pasar `products` como **array** (ojo: data es objeto).

---

## 2) RUTA restringida: carrito

**Crea** `routes/cart.js` con:

* `GET /cart` → renderiza `cart.ejs`
* Solo entra si hay `req.session.user` (`checkLogin`).
* Muestra lo que hay en `req.session.cart` (si no existe, array vacío).

---

## 3) Admin products: tabla + buscador + borrar

En `routes/admin.js` añade:

### A) `GET /admin/products`

* Soporta buscador: `/admin/products?q=go`
* Filtra por nombre
* Renderiza `admin_products.ejs` con `{ products, q }`

### B) `POST /admin/products/:id/delete`

* Borra producto por id
* Pone `req.session.message = "Producto eliminado"`
* Redirige a `/admin/products`

---

## 4) Crear producto (GET + POST)

### A) `GET /admin/products/new`

* Renderiza `admin_products_new.ejs`

### B) `POST /admin/products`

* Lee `{ name, price }` desde `req.body`
* Si falta algo: `req.session.error = "Faltan campos"` y redirect a `/admin/products/new`
* Si va bien:

  * crea producto en `database.products.data`
  * redirect a `/admin/products`
