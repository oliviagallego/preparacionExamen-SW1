### CORRECCION:
- Linea 1: <!DOCTYPE html>, la declaracion de tipo de documento siempre va con una exclamacion antes del doctype.
- Linea 8: <h1>Bienvenido</h1>, hay que borrarla por que no se debe poner los enlazadores en el head, van en el body.
- Linea 12:  <p id="intro" id="intro2" class="1rojo grande"> Hola </p> <div> mundo </div>, los contenedores  div van por fuera de los parrafos (p).
- Linea 13: <img src="logo.png" alt="algo" width="200" height="150">, todos los valores deben ir entre comilals ("logo.png"), alt tiene que tener un valor obligatoriamente, y width/height se esperan como número (pixeles) sin px.
- Linea 17: <li>Uno</li>, falta el cierre.
- Linea 22: <th>Nombre</th>, en la primera tr (table row) ponermos las cabeceras solo th (table head), y no se pueden mezcla con las celdas de datos td (table data).
- Linea 26: <td>Ana</td> <td>20</td>, faltaba una apertura y un cierre para que los datos fueran en celdas separadas, y en cuyo caso el dato fuese Ana20, el td de en medio sobraba.
- Linea 30: <label for= "email">Correo</label> el label debe tener siempre un for (si en linput está fuera del label) que lo relacione con el type del inpu, da un fallo de accesibilidad.
- Linea 32: <label for="password">Contraseña</label>, el for del label debe cuincidir con el id del input.
- Linea 34: <input type="checkbox" checked> Acepto condiciones, checked es atributo booleano: si está presente, es “true” .
- Linea 38: <br>, es un void element por lo tanto no tiene cierre.
- Linea 39: <!-- comentario -->, comentario mal cerrado.

### Errores :
- Linea 7: <link rel="icon" type="image/png" href="C:\icons\favicon.png" >, en tipe de un link va antes del la ruta href.
  - Esto es erróneo por que el orden de atributos no importa en HTML.
  - Lo que está mal aquí es que la ruta debe ser así: href="/icons/favicon.png"
- Linea 9: <script href="app.js"></script>, el script a un archivo JavaScript va en el body.
  - “El script va en body” → no siempre. Puede ir en head (se usa mucho), pero normalmente con defer: <script src="app.js" defer></script>
  - Tambien falla aquí:  href="app.js", que se debe escribir  src="app.js".
- Linea 14:  <a href="https://example.com" target="_self">Ir</a>, solo hay dos tipos de target: "_self" o "_blank".
  - Realmente esto es una trampa, por que target puede ser cualquier nombre.
- Linea 29: <form action="enviar" method="PUT">, la accion va sin /.
  - Realmente el action puede llevar o no /.
  - Error real: method="PUT" --> En HTML, el método del formulario es GET o POST. Si pones otro, el navegador lo trata como GET.
- Linea 31: <input id="email" name="email" type="email" required placeholder="mail@ejemplo.com">, el input debe contener nombre y id.
- Linea 35: <button type="submit">Enviar</button>, el boton enviar es de type submit para que funcione el envio de formulario.
  - Es buena practica pero no es un fallo.
